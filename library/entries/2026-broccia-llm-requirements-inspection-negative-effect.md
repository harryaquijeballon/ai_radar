# Human-AI Collaboration in Requirements Engineering: Evidence of the Negative Effect of LLMs on Requirements Inspection

## Summary

The authors ran a controlled crossover-design experiment with 34 participants inspecting requirements specifications for defects ("smells"), both with and without LLM assistance. LLM support negatively affected smell-detection accuracy, while showing no significant effect on defect-classification accuracy or inspection duration. Across the two experimental periods, a learning effect was observed for participants, but it was reduced when requirements inspection was first performed with LLM support — suggesting that starting with LLM assistance can impede skill development, particularly for less-experienced inspectors. The authors conclude LLM support "does not necessarily improve performance and may, instead, hinder it" in this task, especially for novices.

## Why it matters

A direct, measured counter-example to the default assumption that pairing a review task with an LLM improves outcomes: for novice requirements inspectors, it can reduce detection accuracy and blunt the learning that comes from doing the task unassisted. For teams introducing LLM-assisted review or inspection workflows (lens 7), this is a concrete reason to consider who is doing the reviewing and when LLM support is introduced in a reviewer's development, not just whether it is available.
