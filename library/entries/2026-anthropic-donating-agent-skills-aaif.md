# Donating Agent Skills to the Agentic AI Foundation

## Summary
Anthropic is donating the Agent Skills standard — an open format in which a
skill is a folder containing a SKILL.md file plus supporting scripts or
reference material — to the Agentic AI Foundation (AAIF), which operates
under the Linux Foundation. Anthropic, Block, and OpenAI co-founded the
AAIF in 2025; it already hosts the Model Context Protocol (MCP), which
Anthropic donated earlier. The donation transfers the Agent Skills name and
logo, its GitHub organization, and the agentskills.io domain. More than 70
agent platforms — including ChatGPT, Cursor, GitHub Copilot, and VS Code —
have integrated the standard since Anthropic first published it in
December 2025.

Going forward, engineers from Anthropic, Google, OpenAI, and other
companies will maintain the standard as individuals; David Soria Parra and
Mahesh Murag are named as Lead Maintainers. Anthropic commits to keeping
Agent Skills "open, community-driven, and vendor-neutral," giving the
community a voice in its direction through the AAIF, and allowing use or
contribution without joining the AAIF. A stated roadmap covers versioned
releases, a formal proposal process, and security guidance for skill
authors and installers.

## Why it matters
For builders, a vendor-neutral governance home for a widely-adopted
interoperability standard reduces the risk that any single company's
commercial incentives will redirect the standard's evolution — directly
relevant to teams that depend on Agent Skills (or plan to) across multiple
vendor platforms. The promised security-guidance roadmap for skill authors
and installers is also a concrete item to track for anyone building or
distributing skills, given the supply-chain risk such interoperable,
executable packages inherently carry.
