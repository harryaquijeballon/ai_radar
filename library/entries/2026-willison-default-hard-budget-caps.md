# We're going to need default hard budget caps on pretty much everything

## Summary

Willison argues pay-as-you-go services should enforce hard budget limits by default, stopping service at a threshold rather than emailing a warning, since coding agents lower the friction of deploying paid resources. He notes AWS launched project spend limits in September 2026 (project paused for the month at the cap) and Google Cloud introduced Spend Caps in July, and recommends a default-on cap with an explicit opt-in for unlimited charges.

## Why it matters

A concrete control for agent deployments: set hard spend caps on any metered service an agent can reach.
