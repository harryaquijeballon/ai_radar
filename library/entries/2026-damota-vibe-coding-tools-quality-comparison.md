# Comparing the Quality of Code Generated by Vibe Coding Tools

## Summary

The authors compare structural code quality across three AI-powered
code-generation platforms — Lovable, v0, and Replit — by building three web
applications with each (nine total) and analyzing them with SonarQube
(issue counts, severity, complexity, duplication). Reported finding: "Lovable
concentrates issues of lower severity but presents a substantially higher
density of code smells per KLOC, while v0 and Replit produce more code with
more aggressive severity profiles" (unverified in detail — full metrics
tables and app descriptions not read beyond the abstract).

## Why it matters

Choosing between vibe-coding tools is usually driven by perceived
productivity, not code-quality trade-offs. This gives a small but concrete,
tool-by-tool structural-quality signal (severity profile vs. code-smell
density) that a team evaluating these platforms could weigh alongside
productivity claims.
