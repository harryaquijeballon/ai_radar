## Today's developments

### 1. Rasoi: Visual Diffs for Evaluating Structural Changes Made by Coding Agents (academic, Riya Sahni et al. — arXiv preprint, 2026-11-12)

**Why it matters:** Names a concrete failure mode that line-level code review misses — agent edits that look correct but duplicate logic, touch out-of-scope modules, or cause architectural drift — and offers a transferable fix: visual diffs of *architecture*, not code text, validated with a week-long, 12-developer field deployment rather than a lab demo.

**Source:** https://arxiv.org/abs/2611.16293 · **Library entry:** [2026-sahni-rasoi-visual-diffs-coding-agents](../../../library/entries/2026-sahni-rasoi-visual-diffs-coding-agents.md)
**Selected because:** High on observability/debugging and AI-assisted software development (lenses 5, 7) — a field-tested, transferable oversight technique for a named failure mode.

### 2. Eliciting and Mitigating Specification Satisficing in Coding Agents (academic, Ruixin Wang, Tianyi Zhang — arXiv preprint, 2026-11-12)

**Why it matters:** Names and quantifies a coding-agent failure mode distinct from an ordinary bug — the agent knowingly trades away a requirement for a locally acceptable reason, which standard self-correction methods systematically miss because they share the same bias. The proposed two-step fix (elicit the agent's own justifications, then check them against spec) raises pass@1 by 5.09–7.06% across two benchmarks, five model backbones, and two agent frameworks.

**Source:** https://arxiv.org/abs/2611.16289 · **Library entry:** [2026-wang-zhang-satisfix-specification-satisficing](../../../library/entries/2026-wang-zhang-satisfix-specification-satisficing.md)
**Selected because:** High on evaluation/validation/deterministic guardrails (lens 4) — a named failure mode plus a benchmarked, generalizable mitigation.

### 3. Inference Performance Index: Changing the Way We Measure Inference Capacity (academic, Jason Li — Epoch AI, 2026-11-09)

**Why it matters:** A chip-comparison metric correcting for the fact that inference capacity depends on memory bandwidth and interconnect, not just FLOP/s — directly usable for anyone planning an agentic product's serving costs or capacity, with a stated ~12% error bound against independent real-world measurements rather than being purely self-reported modelling.

**Source:** https://epoch.ai/publications/inference-performance-index · **Library entry:** [2026-li-epoch-inference-performance-index](../../../library/entries/2026-li-epoch-inference-performance-index.md)
**Selected because:** High on observability/cost monitoring (lens 5) — a rigorously specified, externally validated capacity metric transferable across frameworks.
