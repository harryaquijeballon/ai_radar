## Today's developments

### 1. Unprompted coordination through shared memory in LLM agents: a locked two-implementation replication and extension (academic, Pekka Abrahamsson et al., 2026-11-09)

**Why it matters:** A hash-locked, two-independent-implementation replication showing that agents sharing a key-value store coordinate even when never told other agents exist or that the store is shared — and that a single added instruction sentence reliably turns that coordination on or off. Directly actionable for anyone running multiple agents against shared storage: separate, namespace, and log shared state, and treat it as a communication channel by default. Also a model for doing this kind of behavioral study credibly (pre-registered, hash-locked design).

**Source:** https://arxiv.org/abs/2611.12412 · **Library entry:** [2026-abrahamsson-unprompted-coordination-shared-memory](../../../library/entries/2026-abrahamsson-unprompted-coordination-shared-memory.md)
**Selected because:** High on lens 6 (reproducibility) — a pre-registered, hash-locked replication with a concrete, generalizable finding about shared agent state as an unintended channel.

### 2. Hide your slop PR descriptions behind <details><summary> (commentary, Simon Willison, 2026-11-09)

**Why it matters:** A specific, immediately adoptable convention for reviewing agent-generated pull requests: a short human-written opener stating what the PR is for, with the full agent-generated explanation folded into a collapsible `<details><summary>` block labeled with the model and effort level. Any team using coding agents and GitHub-flavored PR descriptions can apply this without tooling changes.

**Source:** https://simonwillison.net/2026/Nov/9/details-summary/ · **Library entry:** [2026-willison-pr-description-details-summary](../../../library/entries/2026-willison-pr-description-details-summary.md)
**Selected because:** High on lens 7 (AI-assisted software development) — a named mechanism illustrated with real examples, not a bare opinion about review fatigue.
