### 1. SkillGate: Cost Efficient Runtime Malicious Skill File Detection in Coding Agents (academic — arXiv:2607.25619, submitted 28 Jul 2026)

**Why it matters:** A directly deployable, cost-aware runtime control for the same skill-security problem this radar has already tracked (SkillSpector, OpenSkillRisk): a hybrid regex+LLM gateway screens agent skill files before installation, reporting an F1 of 0.817 at a 1.13% false-positive rate while cutting LLM token cost by 77% versus full-file analysis — concrete numbers a team could use to decide whether to gate third-party skill installation.

### 2. SafeFlow: Semantic Information-Flow Control for Blocking Malicious Propagation in Multi-Agent Systems (academic — arXiv:2607.25255, submitted 28 Jul 2026)

**Why it matters:** A concrete architectural control for a distinct multi-agent failure mode: a harmful goal split into subtasks that individually look innocuous to each agent, evading per-agent safety checks. SafeFlow tracks semantic "taint" through a dynamic cross-agent graph and validates actions against accumulated taint before execution, tested across four attack types (prompt injection, jailbreak-driven tool misuse, risky code execution, harmful web-agent behaviour) with reported reductions in attack success while preserving benign-task performance.

**Source:** https://arxiv.org/abs/2607.25255 · **Library entry:** [2026-dai-safeflow-multiagent-injection-defense](../../../library/entries/2026-dai-safeflow-multiagent-injection-defense.md)
**Selected because:** high on reproducibility/security/governance; arXiv abstract fetched and traced directly; a distinct, benchmarked control for composed-goal attacks rather than single-agent prompt filtering.

### 3. Learning from 53.6K Real-World Developer Edits of AI-Generated Code (academic — arXiv:2607.25130, submitted 27 Jul 2026)

**Why it matters:** A large, real (not synthetic) dataset — 53.6K in-IDE edits from over 1,000 developers — quantifying how often and how fast developers actually rework or discard AI code completions: most edits land within 15 minutes of acceptance, and 31% of trajectories end in the completion being removed entirely, a concrete correction to teams relying on raw acceptance-rate metrics. The authors also show small models finetuned on this real edit data outperform frontier LLMs at predicting the edit itself — a transferable practice for building edit-prediction tooling.

**Source:** https://arxiv.org/abs/2607.25130 · **Library entry:** [2026-liang-decode-developer-edits-ai-code](../../../library/entries/2026-liang-decode-developer-edits-ai-code.md)
**Selected because:** high on AI-assisted software development; arXiv abstract fetched and traced directly; a large real-world dataset with a measured behavioural finding and a transferable modelling result.
