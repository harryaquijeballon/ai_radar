## Today's developments

### 1. The Memory Heist — PII exfiltration via chained web_fetch (primary — Ayush Paul security write-up, 9 Jul 2026)

**Why it matters:** A working, reproducible exfiltration chain on a tool-using assistant, with a precise root cause: `web_fetch` was allowed to follow links **embedded in already-fetched pages**, so a honeypot could walk nested URLs that spell out private data in the path. For anyone building agents that both read private context and fetch URLs, the lesson is concrete — the dangerous capability is following links from fetched content, and the guardrails (constrain tool-chaining, treat fetched-page links as untrusted, observe outbound URL patterns) apply directly. Reported vendor mitigation: restrict `web_fetch` to user-provided and search-returned URLs. A corroborated security finding, described for defense — not an endorsement.

**Source:** https://www.ayush.digital/blog/the-memory-heist · **Library entry:** [2026-paul-memory-heist-claude-exfiltration](../../../library/entries/2026-paul-memory-heist-claude-exfiltration.md)
**Selected because:** high on the security/guardrails lens; primary source read and independently corroborated; a directly applicable threat-model lesson.

### 2. grok-build — open-sourced terminal coding agent in Rust (primary — xAI GitHub repository, Apache-2.0, surfaced 15 Jul 2026)

**Why it matters:** A full production coding agent released as readable source — leader/stdio/headless runtime split, tool implementations, checkpoints, sandboxing, and MCP support. Most agent-architecture guidance is prose about someone else's system; this is a harness you can read. Useful as a concrete reference when designing a reliable agent for research or policy workflows, where the harness — not the model — carries most of the reliability.
