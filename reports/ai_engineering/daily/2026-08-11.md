### 1. AI Evaluation Should Measure Verification Cost, Not Correctness Alone (academic, Viviana Crescitelli, Generoso Immediato, Fabio Persia, Stefania Costantini — arXiv preprint, 2026-08-09)

**Why it matters:** A near-direct statement of the case for verification-aware evaluation of research/policy AI products: correctness alone is an insufficient reliability metric if the errors that remain are specifically the ones a verifier struggles to catch within a realistic effort budget. Empirical evidence across code generation and multi-modal document understanding shows high benchmark accuracy can mask large real-world verification effort — any evaluation harness with a human-in-the-loop review step should budget for this.

**Source:** https://arxiv.org/abs/2608.08709 · **Library entry:** [2026-crescitelli-verification-cost-ai-evaluation](../../../library/entries/2026-crescitelli-verification-cost-ai-evaluation.md)
**Selected because:** High on lens 4, the profile's stated core lens for the policy-simulation interest — evaluation validity beyond raw correctness.

### 2. OpenCodeReview: Determinism over Non-Determinism for Cost-Effective Agent-Based Code Review (academic, Zhengfeng Li, Lei Zhang, Xianwei Wu, Zhengqi Zhuang, Yingjie Xu, Boge Wang, Shaofei Zhu, Chuan Wang, Guoping Rong — arXiv preprint, 2026-08-10)

**Why it matters:** A concrete, quantified instance of deterministic guardrails around a stochastic component: constraining an LLM code-review agent's autonomy at three specific pipeline points (rule-based dispatch, bounded tool use, independent reflection) delivers up to 2.17x higher precision and 5-15x fewer tokens than unconstrained agent baselines, and the system is open-sourced.

**Source:** https://arxiv.org/abs/2608.09290 · **Library entry:** [2026-li-opencodereview-deterministic-agent-review](../../../library/entries/2026-li-opencodereview-deterministic-agent-review.md)
**Selected because:** High on lenses 4/5 — a reusable, quantified guardrail pattern for a common agent workflow.

### 3. Independent Patch Verification for Coding Agents with a Bidirectional Reconstruct-and-Verify Framework (academic, Chenglin Li, Yisen Xu, Zehao Wang, Shin Hwei Tan, Tse-Hsun (Peter) Chen — arXiv preprint, 2026-08-09)

**Why it matters:** Addresses a specific, common reliability gap directly: once a coding agent produces a patch, nothing independently checks whether it actually resolves the reported problem. RETRACE's training-free, bidirectional reconstruct-and-verify framework improves SWE-bench Verified Pass@1 by 3.6-7.0 points and generalizes to a second agent framework without modification.

**Source:** https://arxiv.org/abs/2608.08950 · **Library entry:** [2026-li-retrace-independent-patch-verification](../../../library/entries/2026-li-retrace-independent-patch-verification.md)
**Selected because:** High on lens 4 — a concrete, quantified independent-verification pattern that doesn't rely on the agent's own self-report.
