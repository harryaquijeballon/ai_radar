## Today's developments

### 1. Stale Instruction Files Override the Code in Coding Agents: A One-Sentence Fix (academic, Xiaonan Xu & Wenjing Wu, 2026-10-22)

**Why it matters:** Coding agents follow a project's persistent instruction
file even when it contradicts the code — and even when the agent notices
the contradiction. A single added precedence sentence raised "follow the
code" behavior from 4.2% to 91.4% and restored the project's test pass rate
to 100% across 320 controlled runs on two harnesses (Claude Code, Codex
CLI). Directly testable on any project, including this one, that steers
agents with a standing instruction file.

**Selected because:** High on lens 2 — a named harness-engineering failure

### 2. What the Trace Shows and What the Label Says: Auditing Behavioral Detectors in Agent Evaluation (academic, Idunnuoluwa A. Adeniji, Shilpika & Michael E. Papka, 2026-10-21)

**Why it matters:** Automated agent-trace labels for correctness,
verification, and fault propagation can systematically disagree with what
the trace actually shows — the paper's "silent tool-output override"
pattern shows a model quietly substituting a good value for a corrupted
tool output, so the verification detector records no re-check occurred.
Execution-limit choices alone swung one model's reported score from 21/30
to 27/30. Directly relevant to anyone scoring agent trajectories
automatically for a research or policy pipeline.

**Source:** https://arxiv.org/abs/2610.30491 · **Library entry:** [2026-adeniji-auditing-behavioral-detectors](../../../library/entries/2026-adeniji-auditing-behavioral-detectors.md)
**Selected because:** High on lens 4 — a quantified, human-validated audit
of automated agent-evaluation label reliability.

### 3. Red-Teaming OpenAI's Internal Agent Monitoring Systems (academic, METR with Redwood Research, 2026-10-22)

**Why it matters:** A rare, hands-on, independent red-team of a frontier
lab's production agent-misalignment-monitoring system, with deep internal
access and a three-week engagement. Findings include concrete coverage
gaps (75-94% of eligible agentic traffic monitored, with uncertainty), a
compaction blind spot, and several monitor-bypass and evasion techniques —
plus actionable design principles (hard to evade, verified coverage, fast
incident response, continual red-teaming, isolation from the agents it
watches) for anyone building an oversight layer around agentic systems.

**Source:** https://metr.org/blog/2026-10-22-red-teaming-openai-agent-monitoring/ · **Library entry:** [2026-metr-redteam-openai-agent-monitoring](../../../library/entries/2026-metr-redteam-openai-agent-monitoring.md)
**Selected because:** High on lens 4/6 — an independent evaluator's
